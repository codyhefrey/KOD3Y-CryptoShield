# Community Code of Conduct

We welcome respectful technical discussion and contributions from people of all backgrounds.

## Expected behavior
Be constructive, considerate, and professional. Critique ideas and code rather than people. Respect privacy, attribution, and security reporting procedures.

## Unacceptable behavior
Harassment, threats, discriminatory abuse, doxxing, spam, intentional disruption, or publication of secrets and private vulnerability details.

## Enforcement
Maintainers may edit or remove inappropriate content, close discussions, or restrict participation when needed. Report conduct concerns privately to repository maintainers using a private channel rather than posting sensitive details publicly. Maintainers should assess reports fairly and protect confidentiality as far as practical.

This policy applies to issues, pull requests, discussions, and other project-managed community spaces.

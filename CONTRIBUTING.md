# Contributing to KOD3Y CryptoShield Community

Thank you for helping improve defensive cryptojacking investigation.

## How to contribute
1. Open an issue describing a bug or proposed feature. Search existing issues first.
2. Fork the repository, create a focused branch, and make your change.
3. Add or update tests and documentation. Run `python -m unittest discover -s tests -v`.
4. Open a pull request explaining the change, test results, and security implications.
5. Wait for maintainer review. Submitting a pull request does not guarantee acceptance.

## Security and privacy
- Never include API keys, passwords, customer telemetry, personal data, or executable malware samples.
- Do not submit cryptominers, unauthorized persistence, exploitation, or evasion features.
- Report vulnerabilities privately according to SECURITY.md, not through public issues.
- Changes involving authentication, process inspection, telemetry, or dependencies receive additional scrutiny.
- Never assume a contributor has permission to test third-party systems.

## Licensing and contributions
The Community repository includes an Apache License 2.0 LICENSE file. By submitting a contribution, you agree that your contribution is intentionally submitted for inclusion under Apache 2.0, consistent with its Section 5, unless you explicitly state otherwise. Submit only work you have the rights to contribute. Do not copy incompatible licensed or confidential code.

## Maintainer authority
Maintainers may request changes, decline contributions, and control official releases. Public contributors do not receive write permissions by submitting a pull request. Enterprise code and internal infrastructure are outside this repository.
